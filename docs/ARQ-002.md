## Quatro Ajustes Obrigatórios Incorporados

1. **RP002-1.0.5 (Dwell time AU915):** não tratar 400 ms como regra universal para uplinks e downlinks; validar DR, payload real e latência ponta a ponta (`latency_ms`) por operação em bancada.
2. **Traccar sem perda de dados:** no Gateway Teltonika nativo o ACK TCP só sai após commit no CORE; no perfil Traccar exige-se banco persistente (`traccar.xml`) + retries + reconciliação, com simulação de CORE indisponível durante `POC-T12`.
3. **LOTO físico como referência absoluta:** `resolve_control_mode()` dá precedência ao estado físico (falha, LOTO físico, seletor local); o software apenas restringe e audita, nunca sobrepõe bloqueio físico.
4. **Regras regulatórias parametrizadas:** tarifa rural flexível (ANEEL 2026), outorga de recursos hídricos (ANA vs órgãos estaduais) e refrigeração de leite (IN MAPA 77/2018) são modeladas via `RegulatoryRule` com autoridade, vigência e parâmetros por cliente/ativo — nunca constantes legais fixas no código.
